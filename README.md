# EA Dashboard — โหมดออนไลน์ (Supabase)

โปรเจกต์นี้แปลง `Time_Breakdown_Dashboard_AppleUI.html` (ไฟล์เดี่ยว เก็บข้อมูลในเบราว์เซอร์ผ่าน IndexedDB)
ให้กลายเป็นเว็บที่ทุกคนเข้าลิงก์เดียวกันแล้วเห็น/อัพโหลด EA และผลเทสชุดเดียวกันได้ โดยใช้ **Supabase**
เป็นฐานข้อมูล + ที่เก็บไฟล์ (ไม่ต้องมีระบบ login ตามที่เลือกไว้)

ระหว่างทำ Phase 2 ผมปรับโครงสร้างตาราง `ea_drafts` ใหม่ (ให้รองรับ EA ต้นแบบที่ไม่ได้อยู่ใน Supabase เช่น Top10/Master Template) ต้องรัน SQL เพิ่มอีก 1 ไฟล์ก่อนใช้งานได้:

1. เปิด Supabase Dashboard → **SQL Editor** → **New query**

## สโคปที่ทำในเฟสนี้ (สิ่งที่ควรรู้)

- **EA ในตัว (Top10)** ยังฝังอยู่ในโค้ดหน้าเว็บเหมือนเดิม (ไม่ได้ย้ายขึ้น Supabase) เพราะ sandbox ที่ผมใช้เชื่อมต่อ Supabase ของคุณโดยตรงไม่ได้ (ติด network allowlist) — ไม่กระทบการใช้งานทั่วไป เพราะ Top10 เป็นข้อมูลอ้างอิงที่ไม่เปลี่ยนอยู่แล้ว
- **การซ่อน/ลบ EA ในตัว (Top10)** ยังเป็นการตั้งค่าเฉพาะเบราว์เซอร์นั้นๆ (เก็บด้วย `localStorage`) ไม่ sync ข้ามเครื่อง/คน — ถ้าอยากให้ share กันได้ด้วย ต้องย้าย Top10 เข้า Supabase เพิ่ม (บอกผมได้ถ้าต้องการ)
- **EA ที่อัพโหลด + ใบสเปคที่สร้างใหม่** sync ผ่าน Supabase เต็มรูปแบบแล้ว ทุกคนที่เข้าลิงก์เห็นชุดเดียวกัน ตรงตามที่ขอ
- ปุ่ม "ดาวน์โหลดสำเนาไฟล์ (สำรอง/ย้ายเครื่อง)" แบบเดิมถูกเอาออก เพราะ Supabase ทำหน้าที่นั้นแทนแล้ว

## ทดสอบแล้วแค่ไหน

ผมทดสอบ logic การเชื่อมต่อ Supabase ทั้งหมด (โหลดรายชื่อ EA, อัพโหลด, ลบ/กู้คืน, ซ่อน/เลิกซ่อน, สร้าง/ลบใบสเปค รวมถึง rollback เมื่อ API พัง) ด้วยการจำลอง Supabase client ปลอมในเครื่องผม — **แต่เชื่อมต่อกับ Supabase โปรเจกต์จริงของคุณโดยตรงไม่ได้** (network ของ sandbox ผมเข้า supabase.co ไม่ได้) ดังนั้นแนะนำให้ทดสอบจริงตามนี้หลัง deploy:

1. เปิด `index.html` (เช่นผ่าน Live Server หรือ deploy ขึ้น Netlify/GitHub Pages)
2. ลองอัพโหลด EA + ผลเทส 1 ตัว → เช็คว่าขึ้นในรายการ และเช็คใน Supabase Table Editor ว่ามีแถวใหม่จริง
3. ลองลบ/กู้คืน EA ที่เพิ่งอัพโหลด
4. ลองสร้างใบสเปค EA ใหม่ 1 ใบ
5. เปิดในเบราว์เซอร์/เครื่องอื่นอีกอัน → ควรเห็น EA/ใบสเปคที่เพิ่งสร้างเหมือนกัน (ยืนยันว่า sync ข้ามเครื่องได้จริง)

ถ้าเจอปัญหาขั้นตอนไหน ส่ง error message มาได้เลย ช่วยไล่ให้ครับ

## ข้อควรรู้เรื่องความปลอดภัย

เพราะเลือกโหมด "ไม่ต้อง login" ตาราง + storage bucket ทั้งหมดเปิดให้ **ใครก็ตามที่มีลิงก์เว็บนี้** อ่าน/อัพโหลด/แก้ไขข้อมูลได้
เหมาะกับใช้ส่วนตัวหรือแชร์ในทีมเล็กที่ไว้ใจกัน ไม่เหมาะกับการแชร์ลิงก์แบบสาธารณะวงกว้าง ถ้าอนาคตอยากล็อกสิทธิ์
เพิ่ม (เช่น อ่านได้ทุกคนแต่อัพโหลด/ลบต้อง login) บอกผมได้ จะกลับมาแก้ RLS policy ในขั้นตอน SQL ให้
